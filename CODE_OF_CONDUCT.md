# Code of conduct

Evalkeeper follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work,
not the person. Harassment, insults, and personal attacks aren't welcome
in issues, pull requests, or anywhere else the project lives.

Report anything that breaks this to the maintainer privately through
[GitHub's private reporting](https://github.com/seanhudson/evalkeeper/security/advisories/new)
or a direct message. Reports are kept confidential.
