# @crowandraven/evalkeeper-prisma

This package is now the `/prisma` entry point of
[`@crowandraven/evalkeeper`](https://www.npmjs.com/package/@crowandraven/evalkeeper).
Install that instead and import from `@crowandraven/evalkeeper/prisma`:

```bash
npm install @crowandraven/evalkeeper
```

This package re-exports it so apps that use it keep working, and will be
retired.
